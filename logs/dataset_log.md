# Dataset Preparation Log

## Script
- File: prepare_dataset.py
- Run: python prepare_dataset.py (from the project root, venv active)
- Output: instances/tuning/, instances/benchmark/, instances/manifest.csv

## What it generates
- Erdős–Rényi graphs: 8, 10, 12, 14, 16, 18, 20 nodes; edge probability 0.25, 0.50, 0.75; 5 graphs per setting
- 3-regular graphs: 8, 10, 12, 14, 16, 18, 20 nodes; 5 graphs per size
- Every graph generated by NetworkX from a recorded seed

## Tuning / benchmark split
- Tuning seeds start at 1001, benchmark seeds start at 5001
- Script asserts the two seed ranges do not overlap

## Ground truth
- Exact Max-Cut optimum computed by brute force (node 0 fixed, 2^(n-1) partitions, vectorised with NumPy)
- Optimum and optimal partition stored in manifest.csv

## File format
- G-set layout: first line "nodes edges", then one "u v weight" line per edge (1-indexed)

## Verification
- Check 1: optimum equals edge count if and only if the graph is bipartite (both directions)
- Check 2: 2,000 random partitions per instance, none may exceed the stated optimum
- Result: 0 verification failures

## Result
- 280 instances: 140 tuning, 140 benchmark (210 Erdős–Rényi, 70 3-regular)
- Runtime: under 30 seconds
